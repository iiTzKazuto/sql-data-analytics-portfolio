This repo holds the projects I've built while learning SQL and Excel. I built each one to practice a real kind of work, not just to follow a tutorial.

## What I practiced

- **SQL:** joins, GROUP BY, subqueries, CTEs, window functions, views, stored procedures, indexes, primary and foreign keys
- **Excel:** cleaning messy data with formulas (TRIM, PROPER, DATEVALUE, INDEX/MATCH), lookup tables, removing duplicates
- **Data quality:** validation checks, reconciliation, setting aside rows I can't fix instead of guessing
- **Business thinking:** turning numbers into recommendations someone could act on

## How to run the projects

Every SQL file is written for MySQL 8.0 and runs in MySQL Workbench.

1. Open the file with **File > Open SQL Script**.
2. For files that build a database, run everything with **Ctrl+Shift+Enter**.
3. For files full of reports, click inside one query and press **Ctrl+Enter** to run just that one.

Each project folder has its own README with the exact steps.
